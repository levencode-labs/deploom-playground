На Mac собирается. Почему Linux CI потерял пакет?

      
На ревью принесли правку lock-файла. Версия Rollup прежняя. Почему из diff исчезли пакеты для Linux, которых на Mac и так не было? При запуске Rollup загружает библиотеку, собранную под конкретную систему. Макбуку коллеги и серверу сборки нужны разные файлы.

      
В тикете npm №7961 разработчик установил Rollup на Mac с M1, macOS 14.5 и npm 10.9.2. Затем он пересоздал package-lock.json поверх уже установленной папки node_modules. Сначала в lock-файле было 18 платформенных пакетов. Во второй раз остался один — для Mac на ARM64.

Откуда взялась эта пара файлов и что исправили в npm?
        
Для лаборатории мы зафиксировали Rollup 4.28.0 и записали два lock-файла с npm 10.9.2 и Node 24.18.0 на Windows x64. Параметры npm --os и --cpu задали целевую платформу darwin/arm64. Повторная установка с сохранённой папкой node_modules дала те же 18 и одну запись. В опыте проверялось содержимое lock-файлов.

        
При восстановлении lock-файла по установленному дереву npm терял необязательные пакеты для других систем. Исправление №8184 сохраняет эти варианты в дереве npm, даже если на текущей машине их установку пропустили. Оно вошло в Arborist 9.0.2 и npm 11.3.0.
