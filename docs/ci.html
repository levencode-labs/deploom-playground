Что проверить в своём PR

      
Выполните npm install --package-lock-only с версией npm и настройками реестра вашего проекта. Посмотрите diff lock-файла, затем запустите npm ci и проверки проекта с настройками CI.

      
Записано на Node 24.18.0 и npm 11.16.0. В изолированном учебном реестре доступны ровно две версии demo-lib — 1.2.3 и 2.0.0. Страница показывает результаты прогонов и работает без сети.
