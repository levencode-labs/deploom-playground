Коллега обновил React DOM. Почему сборка остановилась на установке?

Коллега поднял react-dom до 18.3.1. В CI установка остановилась ещё до запуска приложения. Поменяйте версию React и посмотрите, какая строка решает, продолжится ли установка.

Прочитайте строку справа налево. После «from» стоит пакет, которому нужен React. После «peer» — какие версии React ему подходят. Сравните этот диапазон с версией приложения выше.

Источник — запись строгой установки npm для этой пары. Нажмите на строку, чтобы выделить требование и выбранную версию.

Разобрать в дереве Открыть свой проект

В своём проекте найдите в логе строку peer … from … и сравните её с версией из npm explain react.

Попросите DepLoom построить план с зафиксированным React, затем разрешите обновить его. Сравните, почему во втором плане появилась ещё одна строка.

Почему при обновлении не установилась 0.3.0?

В package.json стоит ^0.2.3. Коллега выпустил 0.3.0, а в lock-файле осталась 0.2.4. Выберите обе версии на шкале и посмотрите, где заканчивается разрешённый диапазон.
