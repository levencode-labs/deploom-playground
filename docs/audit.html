Пути, исключённые из внешней проверки

      В Yarn Berry запись npm: указывает тип пакета, а адрес реестра может быть корпоративным. Подтверждайте только действительно публичные имена. Перед запросом к OSV браузер сверит выбранные версии с публичным реестром npm. Этим сервисам передаются только выбранные названия и версии. Файл и пути остаются в браузере.

      Кнопка «Сравнить с npm latest» запрашивает выбранные публичные имена в registry.npmjs.org. Тег latest может указывать на другую мажорную ветку. Проверьте изменения API, прежде чем выбирать цель.
