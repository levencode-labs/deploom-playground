Какие версии библиотек использует проект?

Откройте lock-файл, чтобы увидеть точные версии библиотек в сборке. Добавьте package.json, чтобы сравнить их с тем, что запросил проект.

Установленные версии

    Записи без точной версии

      Выберите публичные пакеты. Их можно сверить по имени и версии с npmjs, даже если в lock-файле указан корпоративный реестр. Отправляются только выбранные строки.

        Пример ответа OSV

        Сохранённый пример проверен 21 ноября 2026 года. В карточке OSV ниже указана lodash 4.17.20. Эта конкретная проблема исправлена в 4.17.21. Если одна версия установлена по двум путям, для неё достаточно одного запроса.

        Пустой ответ означает, что источник не вернул известных записей для этой версии. Исключённые пути и незавершённые запросы остаются за пределами подтверждённой проверки.
