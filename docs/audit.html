Проект Пакет

Выберите lock-файл вверху страницы. Добавьте package.json, чтобы определить прямые зависимости.

Учебные package.json и lock-файл воспроизводят одну ветку тестового проекта. В проекте Vitest подключён как dev-зависимость. Vitest 3.2.6 запрашивает tinypool ^1.1.1, а в сокращённом lock-файле выбрана версия 1.1.1. В примере разобраны две записи OSV для Tinypool.

Раскройте карточку, чтобы увидеть, через какую зависимость установлен Tinypool. По данным OSV, проблему в параметрах воркера исправили в 2.1.1, а в параметрах run() — в 2.1.2. Обе версии выходят за диапазон ^1.1.1.

Как считаем

Каждая запись источника учитывается один раз для всех версий и копий. npm audit дополнительно учитывает пакеты, затронутые через уязвимую зависимость.

Отставание — разница дат публикации установленной и старшей стабильной версии. Доля рассчитана по прямым зависимостям, для которых известны обе даты.
