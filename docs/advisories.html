Проверить версию пакета

У двух версий одной библиотеки могут быть разные известные уязвимости. Возьмите точную версию из lock-файла проекта.

Проверить по базе OSV

По кнопке браузер отправит название и версию на api.osv.dev. Вводите только публичные названия пакетов.

    Проверить ту же версию в GitHub Advisory Database (JSON)
    При открытии ссылки GitHub получит публичное имя пакета и версию.

    Пример для разбора без сети

    lodash@4.17.20 · Карточка проверена 21 ноября 2026 года

    В этой версии lodash известна уязвимость, связанная с выполнением команд. Первое исправление для этой конкретной проблемы вышло в версии 4.17.21.

    Проверьте обе версии выше и поищите этот идентификатор. Для новой версии могут оставаться другие записи.
