Сравнить два lock-файла

Что изменилось после обновления? Сравните два корневых npm-файла package-lock.json версии 3. Каждая установленная копия имеет свой путь. Выберите одну, чтобы увидеть, как она связана с проектом.

Lock-файлы

Выберите два файла до 20 МиБ каждый. Браузер читает их на вашем устройстве и переключается с примера на вашу пару.

Изменения по месту установки

Учитываются изменения версий и метаданных. При переносе копии один путь исчезает, другой добавляется. Корень самого проекта в счётчики не входит.

    Для каждой стороны показан один найденный путь по объявленным зависимостям до выбранной копии. По одному только расположению каталога нельзя определить, кто запросил пакет.
