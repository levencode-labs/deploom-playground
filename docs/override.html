      Как проверить путь у себя
      
      
      Вызовите npm ls shared-utils --all, чтобы увидеть все копии. Передайте точный путь из своего lock-файла в npm explain и посмотрите, какой пакет её установил. У каждого родителя свои проверки.
      
      
      В учебном проекте выбран режим установки npm nested, поэтому видны оба физических пути. При стандартном подъёме пакетов пути могут отличаться. Имена и версии здесь учебные.
