Почему npm не даёт обновить только React DOM?

Приложение выбирает версию React. React DOM указывает диапазон, с которым умеет работать.

React в приложении

Источник — запись строгой установки npm для этой пары. Нажмите на строку, чтобы выделить требование и выбранную версию.
