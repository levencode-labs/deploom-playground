Лаборатория обновлений

Какие версии можно поставить вместе? Что проверять после установки? Меняйте условия и смотрите, на каком шаге ломается обновление.

Инструменты для своего проекта

Дерево зависимостейВставьте package.json. Добавьте lock-файл, чтобы увидеть вложенные версии и несовпадающие требования. Проверить уязвимостиУкажите имя публичного npm-пакета и точную версию, чтобы найти опубликованные записи в OSV.

Три опыта с версиями

Что обновить вместе с React DOM?Четыре сочетания двух версий. Только одно из них отвергает npm. Установка прошла. А кнопка?Обновите React и проверьте старый вызов, который рисует кнопку. Сколько пакетов придётся тронуть?Закрепите соседний пакет и посмотрите, какие варианты останутся у сборщика и плагина.
