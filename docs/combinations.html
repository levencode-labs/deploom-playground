Почему для одного обновления нужны три правки?

Вы хотите обновить плагин до версии 2. Сейчас у всех трёх пакетов версия 1. Сборщик можно обновить, а соседний модуль пока закрепляет адаптер. Проследите требования по цепочке и попробуйте изменить это условие.

  2. Сборщик · v2Можно менять. С таким сборщиком работает только адаптер v2.
