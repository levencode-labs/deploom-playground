Статус на месте. Куда после обновления делась подсказка?

После перехода на React 19 команда заметила это уже при использовании приложения. Иконка статуса осталась на месте. Человек навёл на неё мышь, чтобы узнать подробности, и ничего не произошло. Ниже можно повторить этот момент.

Источник — упрощённый компонент, который работает прямо в браузере на React 19.0.0. Оба варианта проходят строгую проверку TypeScript.

Какую проверку взять в свой PR?

Через ref подсказка получает ссылку на элемент страницы. Компонент может принять ref и забыть передать его кнопке — оба варианта допустимы для TypeScript. В тесте наведите мышь на статус и дождитесь текста подсказки. Проверка одной иконки эту ошибку пропустит.

DepLoom помогает согласовать версии React и React DOM. Для этой поломки решающая проверка — тест наведения. В опыте миграции стоит сохранить конкретную подсказку коллеге: «после обновления открой статус и проверь, что пояснение появилось».

Ещё один случай — как заметить поломку кнопки на сервере

Сервер тоже умеет рисовать страницу: он вызывает React и отправляет браузеру готовый HTML. Это и есть SSR. Здесь серверу поручили вернуть одну кнопку с надписью OK. Старая функция исчезла из React 19. Сравните результат до и после замены вызова.
