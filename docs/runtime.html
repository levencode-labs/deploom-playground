Статус на месте. Куда после обновления делась подсказка?

Это случай с подсказкой из статьи. После перехода на React 19 иконка статуса осталась на месте. Коллега навёл на неё мышь, чтобы узнать подробности, и ничего не увидел. Попробуйте повторить это на упрощённом компоненте.

Оба варианта подсказки работают на React 19.0.0 и проходят строгую проверку TypeScript. Меняется только то, как обёртка передаёт ref кнопке.

Какую проверку взять в свой PR?

Через ref подсказка получает ссылку на элемент страницы. Компонент может принять ref и забыть передать его кнопке — оба варианта допустимы для TypeScript. В тесте наведите мышь на статус и дождитесь текста подсказки. Проверка одной иконки эту ошибку пропустит.

В этой миграции проверка зависимостей пропустила поломку. В lock-файле видно, какой React установился. Передала ли обёртка ссылку на кнопку, видно только при взаимодействии с компонентом. Попробуйте один и тот же тест до и после исправления.

Запись для следующего обновления React 19

React 18 → 19. Если у статуса есть подсказка, наведите на него мышь или перейдите к нему клавишей Tab. Должен появиться текст пояснения. Если виден только статус, проверьте, передаёт ли обёртка ref кнопке. Добавьте эту проверку в UI-тесты.

Эту запись можно положить в чек-лист обновления проекта. Если команда пользуется DepLoom, её можно добавить в предложение поделиться опытом по итогам миграции.
